# Banc d'essais mécaniques pour biomatériaux

Adaptation de la Low Cost Universal Tensile Testing Machine (Xieshi Zhang / CrazyBlackStone)
pour la traction de films de cellulose bactérienne, la compression de mycélium
et la flexion 3 points de composites minéralisés.

- Projet source : https://github.com/CrazyBlackStone/Universal-Tensile-Testing-Machine
- Licence d'origine : GPL-3.0 (code et fichiers repris dans /original)
- Plage visée V1 : 0–500 N, cellules ~10 kg et ~50 kg
